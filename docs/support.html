Support

Install tips, controls, aur common fixes — DIANO smoothly chalane ke liye.

Quick answers

Pehle yahan check karo — zyada tar cheezein yahin clear ho jaati hain.

Install kaise karein?

Chrome Web Store se “Add to Chrome” dabao, phir DIANO icon pin karo. Developer mode se load kar rahe ho to folder select karke Load unpacked use karo.

New tab pe game nahi aa raha

Toolbar popup mein Game on new tab ON rakho. Phir naya tab kholo. Agar purana tab open hai to usko refresh / naya tab try karo.

Keyboard controls change karne hain

Extension icon → Jump / Duck pe Change → naya key press. Esc se cancel. Reset to defaults se Space / ↑ / ↓ wapas aa jaate hain.

Sound nahi aa raha

Popup mein Sound effects ON rakho. Pehli baar jump/start pe browser audio unlock hota hai — ek baar Space dabao.

✕ button kya karta hai?

New tab pe top-right ✕ Chrome default new tab / Google pe le jaata hai — jab aapko normal browsing chahiye.

High score reset

Popup → High score → Reset. Local storage clear ho jaati hai for HI only.

Still stuck?

Bug ya feature request GitHub Issues pe bhejo — screenshot add kar dena.
