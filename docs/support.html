Support

Install tips, controls, and common fixes to keep DIANO running smoothly.

Quick answers

Check these first — most issues are covered here.

How do I install DIANO?

Click “Add to Chrome” on the Chrome Web Store, then pin the DIANO icon. If you are loading unpacked for development, choose this folder in chrome://extensions.

The game does not appear on new tabs

Open the toolbar popup and turn Game on new tab ON. Then open a fresh new tab. Refresh older tabs if needed.

How do I change keyboard controls?

Open the extension popup → Jump / Duck → Change → press a new key. Press Esc to cancel. Use Reset to defaults for Space / ↑ / ↓.

I do not hear sound

Turn Sound effects ON in the popup. The browser unlocks audio after the first jump or start — press Space once.

What does the ✕ button do?

The top-right ✕ on the new tab takes you back to Chrome’s default new tab page or Google when you want normal browsing.

How do I reset my high score?

Popup → High score → Reset. Only the local HI value is cleared.

Still stuck?

Send a bug report or feature request on GitHub Issues — include a screenshot if you can.
